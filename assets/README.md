# Assets Folder

This folder contains all static assets for the portfolio website.

## Structure

- **images/** - Store all images here:
  - Profile photo (e.g., `profile.jpg`)
  - Project screenshots (e.g., `project-hr.png`, `project-smartbite.png`)
  - Background images if needed
  - Logos or icons

## Recommended Image Sizes

- **Profile Photo**: 400x400px (square, optimized for web)
- **Project Screenshots**: 800x600px or 1200x900px (landscape)
- **Favicon**: 32x32px or 64x64px (.ico or .png)

## Optimization Tips

- Use WebP format for better compression
- Optimize images before uploading (use tools like TinyPNG)
- Keep image file sizes under 500KB when possible
